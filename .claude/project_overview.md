# Lucky Reference: project overview

JUCE 9 (CMake + Ninja, fetched via FetchContent) VST3 reference plugin for the master track, a sibling of Lucky Seven (`../lucky-seven`). Licensed AGPLv3. The agreed v1 behaviour is in `docs/spec.md`. `docs/index.html` (+ `docs/assets/`) is the GitHub Pages promo site, styled like Lucky Seven's; screenshots come from `LuckyReferenceSnapshot` (`reference`, `loaded`).

## Layout
- `Source/PluginProcessor.*`: parameters `reference` (the A/B switch, first so it is easy to put on Ableton's device panel), `slot` (1-3), `match`. Slot file paths and loops live as `Slot` children of the APVTS state, loops in seconds so they survive a sample-rate change. Loads files through `ReferenceLoader` and, for a newly loaded file, sets the loop to its loudest 16 s. Offline renders (`isNonRealtime`) return the mix untouched.
- `Source/PluginEditor.*`: `LuckyReferenceEditor` scales a fixed 900x600 `LuckyReferenceView` (Lucky Seven's pattern: Window size menu, scale saved by `ui/Settings.h`). The view has the top bar (seven-segment A/b logo that returns to REFS, separators, REFS/LIBRARY tabs, three-dot menu with Library folders), three `SlotRow`s, and a stage: readout ("YOUR MIX VS REF n / 3.4 dB quieter" plus LUFS), `RadarRipples` behind the `SourceSwitch` (the readout is a `PaintLayer` above them), LEVEL MATCH in the selected slot's colour, and a keycap shortcut hint (`paintShortcutHint`). Keys: left/right mix/reference, 1-3 slot, Delete clears the selected slot.
- `Source/dsp/LoudnessMeter.*`: BS.1770-4 gated loudness. Streaming over a rolling 10 s window of 400 ms blocks (plus momentary), and offline helpers working on 100 ms K-weighted slice energies.
- `Source/dsp/ReferenceEngine.*`: per block: adopt new slot sources, follow the transport (start restarts every reference at its loop start and resets the mix meter; a jump resets the meter; a host loop wrap doesn't), measure the mix while playing, set each slot's gain to `mix LUFS - loop LUFS` (clamped ±24 dB, ramped 1 s; matching starts after 1.5 s, and a selected reference is silent until the first estimate, then fades in), 30 ms equal-power source crossfade. Exposes mix momentary loudness, applied gains and play state for the radar. Bit-identical pass-through while on the mix.
- `Source/dsp/ReferencePlayer.*`: one per slot; loop playback with a 10 ms crossfade at the loop point. `Handoff.h`: lock-free message-to-audio handoff with a retire queue.
- `Source/library/ReferenceLibrary.*`: the reference library (`~/Music/Lucky Reference/References`, or `$LUCKY_REFERENCE_LIBRARY`; cache and added folders (`folders.json`) in Application Support or `$LUCKY_REFERENCE_STATE`). Shared via `SharedResourcePointer`, held by the processor (`getLibrary()`). `addFolder`/`removeFolder` index extra folders in place (entry key = full path for those). Rescan lists files on the calling thread; a low-priority thread reads format and length, cached by path/size/date. `importFile` copies a file in (reuses same name+size). `LuckyReferenceProcessor::relinkFile` points a slot at the copy without reloading. Each entry also gets a cached `TonalProfile` (`analyseFile` streams the file); `sortClosestFirst` ranks against a mix.
- `Source/library/TonalProfile.*`: 27 third-octave bands (31.5 Hz-12.5 kHz, relative to their average) plus punch (median peak/RMS of 1 s windows), gated over a second of context; `distance`/`match`. `TonalAnalyser` takes mono audio in any block size, optionally over a sliding window.
- Mix profile: `ReferenceEngine` copies the mono mix into a lock-free FIFO while playing (`readMixTap`); the processor's 2 Hz timer drains it into a 120 s `TonalAnalyser` (`updateMixProfile`, `getMixProfile` once 20 s are heard).
- `Source/ref/`: `ReferenceTrack` (decoded stereo at host rate, overview peaks, loudness slices, momentary loudness at a position, loudest-section search), `Resampler` (macOS AudioConverter), `FileFormat` (badge label; lossy bitrate via AudioFile), `ReferenceLoader` (background decode, newest request per slot wins), `LoopRegion`.
- `Source/ui/`: `LibraryPanel` (the LIBRARY tab over the slot rows; search, A-Z/CLOSEST with match bars, blank CLOSEST state until the mix is ready, 1 2 3 load buttons per row, ADD FILES imports, empty state), `SlotRow` (empty click browses; hover × removes; ADD TO LIBRARY once the library has been opened), `SourceSwitch` (spring knob), `RadarRipples` (Lucky Seven-style ripples and glow from the knob), `SegmentGlyph`, `Settings`, `Theme` (slot 1 gold, 2 pink, 3 green), `LookAndFeel` (from Lucky Seven; adds a `toggle` outline button style).
- `Tests/`: `LuckyReferenceTests` (DSP and loading, category "Lucky Reference") and `LuckyReferenceProcessorTests` (links the plugin; parameters, export safety, state, auto loop).
- `tools/Benchmark.cpp`: engine CPU per block at 32-512 samples. `packaging/` + `.github/workflows/`: Lucky Seven's release pipeline adapted for VST3 only (tag `v*` -> pkg + zip).
- `tools/Snapshot.cpp`: renders the editor to PNG with generated references (`empty|loaded|reference|measuring|nomatch|radar|playing|library|library-empty|closest|outside`), in a sandboxed temp library. `tools/LoadBenchmark.cpp`: times loading a file (or `--synthetic` 4-minute song). `tools/ProfileTool.cpp` (`LuckyReferenceProfile <files>`): analysis time, punch, tilt and pairwise matches of real files.

## Notes
- Tests generate AAC fixtures with `/usr/bin/afconvert`.
- The plugin build uses LTO and is universal, so linking takes over a minute; build `LuckyReferenceTests` alone for quick DSP iteration.
